## [2.0.0](https://github.com/mokevnin/1mail/compare/v1.0.0...v2.0.0) (2026-08-17)


### ⚠ BREAKING CHANGES

* drop echo/v4, oapi-codegen/runtime and kin-openapi; add ogen as a tool dependency. `make test` now runs `go test -p 1`. Segments and broadcasts endpoints return 501 (unimplemented); api-token last_used_at is no longer updated on each request.

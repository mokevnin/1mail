# API reference

Every operation of the external API (`/api`, Bearer token), generated from the OpenAPI document
that TypeScript and Go clients are built from. Pick an operation in the sidebar. Authentication,
scopes, pagination and errors are explained in the [API guide](/guide/api).

The raw document is
[`openapi/external.openapi.json`](https://github.com/mokevnin/1mail/blob/main/openapi/external.openapi.json)
in the repository.
